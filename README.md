# 🐻 草地打滚的小熊

一个单文件的 H5 小游戏：小熊在草地上滚来滚去，压扁小草和花朵，收集蜂蜜和草莓补充体力，躲开大石头和捣蛋的小蜜蜂。全程 Canvas 绘制，无任何外部图片/依赖，手机和电脑都能玩。

## 玩法

| 操作 | 方式 |
| --- | --- |
| 向左滚 | 按住屏幕**左半边**（电脑：`←` 或 `A`） |
| 向右滚 | 按住屏幕**右半边**（电脑：`→` 或 `D`） |
| 跳跃（跳过石头） | 轻点一下屏幕（电脑：`空格` / `↑` / `W`） |
| 暂停 / 静音 | 右上角按钮 |

- 🍯 蜂蜜：+26 体力，+20 技巧分
- 🍓 草莓：+6 体力，+5 技巧分
- 🌸 压过花朵：+1 体力，+1 技巧分
- 🔥 **连击**：3.5 秒内连续收集道具，技巧分 ×N（最高 ×10），被撞断连
- 🪨 石头挡路：轻点屏幕**跳过去**；撞上 -10 体力并弹开
- 🗻 沟壑（22 秒后出现）：地面裂缝，**掉进去直接结束**，必须提前跳
- 🪨 滚石（40 秒后出现）：迎面滚来的巨石，跳过去或挨撞 -15 体力
- 🐝 被蜜蜂蛰：-14 体力并击退；50 秒后可能同时有两只蜜蜂
- 💦 水坑：减速并加快体力消耗
- ⚡ 难度曲线：体力流失、障碍密度、蜜蜂速度、滚石速度都随时间加快
- 体力归零或掉进沟里游戏结束；**总分 = 米数 + 技巧分**（技巧分已含连击加成）

## 本地试玩

直接**双击 `index.html`** 即可在浏览器打开（所有资源都内联在文件里，无需服务器）。

也可以起一个本地服务器（可选）：

```bash
# 在本文件夹内执行任意一条
python -m http.server 8000
# 或
npx serve .
```

然后手机和电脑在同一 Wi-Fi 下，用手机浏览器访问 `http://<电脑IP>:8000` 即可试玩触屏效果。

## 发到微信聊天里玩

1. **上传到公网**：把 `index.html` 放到任意静态托管服务，例如
   - GitHub Pages（免费，推荐）
   - Gitee Pages（国内访问快）
   - Vercel / Netlify / Cloudflare Pages
   - 自己的服务器（国内服务器域名需 ICP 备案）
2. **把链接发到微信聊天**（直接发 URL 或「+ → 文件 → 分享链接」），对方点击后用微信内置浏览器打开即可玩。
3. 首次打开非备案/非白名单域名时，微信可能提示「非微信官方网页」，点「继续访问」即可，不影响游戏。
4. 建议使用 **HTTPS** 链接：体验更好，且部分功能（如音频）在 HTTPS 下更稳定。

> 小提示：在微信里打开后，点右上角「···」可以「浮窗」或「发送给朋友」，方便随时再玩。

## 自定义修改

所有玩法参数都在 `index.html` 中 `<script>` 顶部的常量区，直接改数值即可：

- `R`：小熊大小；`MAXS` / `ACC`：最大速度 / 加速度
- 体力消耗系数（`updatePlay` 里的 `2.6`、`0.6`、`1.5`）
- 拾取/受伤数值（蜂蜜 `+26`、草莓 `+6`、石头 `-10`、滚石 `-15`、蜜蜂 `-14`）
- 连击：`comboTime = 3.5`（秒）、`comboMult()` 上限 ×10
- 地形起伏：`terrainY()` 里的正弦振幅
- 沟壑出现时间：`spawn()` 里的 `playTime > 22`；滚石：`updatePlay` 里的 `playTime > 40`；蜜蜂：`beeTimer = 15`（秒）

## 兼容性说明

- 支持微信内置浏览器、Safari、Chrome、Edge 等现代浏览器（iOS 12 / Android 7 以上）
- 首次点击才会出声（浏览器自动播放限制），右上角可静音
- 最高分保存在浏览器 `localStorage` 中
